# Security Policy

## Supported versions

This repository is the source of the scrapup website (scrapup.dev). Only the latest release deployed
to production receives security fixes.

| Version | Supported |
|---|---|
| Latest release (deployed to production) | Yes |
| Older releases | No |

## Reporting a vulnerability

Do **not** open a public issue, discussion or pull request for a vulnerability.

Report it privately through GitHub:
[Report a vulnerability](https://github.com/scrapup/scrapup-site/security/advisories/new)
(Security tab → *Report a vulnerability*).

Include the affected page or commit, a description of the impact and the steps to reproduce.

## Response

Reports are handled on a best-effort basis by the maintainer. You will receive an acknowledgement
on the advisory, and the fix is released through the normal release flow (a new `vX.Y.Z` tag and
production deploy) with the advisory published after the release.
